## 🌸 О проекте

**Scissors Bar** — это стильный одностраничный сайт для бара с уникальной концепцией, ориентированной на женщин. Сайт выполнен в элегантной черно-розовой гамме с каллиграфическими акцентами и плавными анимациями.

Сайт рассказывает историю бара, представляет меню с коктейлями и закусками, а также содержит контактную информацию.

## 💫 Концепция

> *Scissors — пространство, созданное для женщин и про женщин. Здесь каждая деталь дышит уважением к женской силе, грации и многогранности.*

Дизайн сайта построен на контрастах:
- 🖤 **Черный** — символ уверенности и глубины, даже небольшой дерзости:)
- 💗 **Розовый** — нежность, страсть и смелость быть собой

## 🛠 Технологии

- **HTML5** — семантическая верстка
- **CSS3** — стилизация, анимации, адаптивность
- **JavaScript** — плавная прокрутка, интерактивность
- **Python** — (опционально) для создания локального сервера при разработке
- **Google Fonts** — подключение шрифтов (Playfair Display, Open Sans)
- **Font Awesome** — иконки для социальных сетей и контактов

## 📦 Установка

### Предварительные требования
- Любой современный браузер (Chrome, Firefox, Safari, Edge)
- Текстовый редактор (VS Code, PyCharm, Sublime Text) — для редактирования кода
- (Опционально) Python 3.x — для запуска локального сервера
